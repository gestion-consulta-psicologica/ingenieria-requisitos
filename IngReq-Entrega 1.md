## Proyecto

### Gestión de consultas psicológicas

El proyecto aborda el proceso de gestión de horas de una consulta psicológica, donde actualmente los pacientes solicitan una hora mediante WhatsApp. La psicóloga revisa manualmente su disponibilidad y coordina con el paciente una fecha y horario para la atención. A partir del análisis del proceso actual, se busca identificar problemas y oportunidades de mejora que permitan proponer un proceso rediseñado.
